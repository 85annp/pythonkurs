Del 1 — Flervalsfrågor

Välj det alternativ du tror är rätt, klicka sedan på "Visa svar" för att kontrollera.

Fråga 1NIVÅ E

Vad skriver koden ut: print("Hej", "världen")

a) HejVärlden
b) Hej världen
c) Hej,världen
d) Ett felmeddelande
Visa svar
Rätt svar: b) Hej världen När man skriver flera delar separerade med kommatecken i print() läggs automatiskt ett mellanslag mellan dem, men inget kommatecken syns i utskriften.
Fråga 2NIVÅ E

Vilken datatyp får variabeln x efter x = "10"?

a) int
b) float
c) str
d) bool
Visa svar
Rätt svar: c) str Eftersom värdet står inom citattecken blir det en textsträng (str), även om det ser ut som ett tal. Man skulle behöva skriva x = int("10") för att få ett heltal.
Fråga 3NIVÅ D

Vad blir värdet av 15 // 4?

a) 3.75
b) 4
c) 3
d) 1
Visa svar
Rätt svar: c) 3 // är heltalsdivision och avrundar alltid nedåt. 15/4 = 3.75, avrundat nedåt blir det 3.
Fråga 4NIVÅ D

Vad blir värdet av 15 % 4?

a) 3
b) 4
c) 0
d) 1
Visa svar
Rätt svar: a) 3 % ger resten vid division. 15/4 går tre hela gånger (12), och det blir 3 kvar. Alltså 15 % 4 = 3.
Fråga 5NIVÅ C

Vilket tecken används för att jämföra om två värden är lika i Python?

a) =
b) ==
c) ===
d) equals()
Visa svar
Rätt svar: b) == Ett enkelt likhetstecken (=) används för tilldelning, alltså att ge en variabel ett värde. Dubbla likhetstecken (==) används för att jämföra om två värden är lika.
Fråga 6NIVÅ C

x = 8. Vilket av följande uttryck blir True?

a) x < 5 or x > 6
b) x < 5 and x > 6
c) x == 5
d) not(x > 6)
Visa svar
Rätt svar: a) x < 5 or x > 6 x < 5 är False (8 är inte mindre än 5), men x > 6 är True (8 är större än 6). Med or räcker det att ett av påståendena är sant, så hela uttrycket blir True.
Fråga 7NIVÅ B

Vad gör raden poäng -= 3?

a) Jämför om poäng är lika med 3
b) Sätter poäng till exakt 3
c) Minskar poäng med 3 (kortform för poäng = poäng - 3)
d) Multiplicerar poäng med -3
Visa svar
Rätt svar: c) Minskar poäng med 3 -= är en tilldelande operator, ett kortare skrivsätt för poäng = poäng - 3. Samma mönster finns för +=, *= och /=.
Fråga 8NIVÅ B

Vilket nyckelord används i Python för "else if", alltså för att kolla ett nytt villkor om det första var falskt?

a) elseif
b) elif
c) elsif
d) otherwise
Visa svar
Rätt svar: b) elif elif står för "else if" och används för att kontrollera ett nytt villkor bara om de föregående villkoren var falska. Man kan ha flera elif efter varandra.

Fråga 3NIVÅ C

Koden nedan ger ett fel när den körs. Vilket fel blir det, och hur rättar du det?

y = 150
if y > 100:
print("Stort tal")
Visa svar
Svar Felet: print-raden är inte indenterad och hör därför inte till if-blocket, vilket ger en IndentationError.
Rättning: indentera print-raden med samma indrag som resten av blocket, t.ex. fyra mellanslag.
Fråga 4NIVÅ B

Koden nedan innehåller ett logiskt fel som gör att den inte fungerar som tänkt. Vad är felet?

kod = 1234
gissning = input("Gissa koden: ")

if gissning = kod:
    print("Rätt!")
Visa svar
Svar Felet: = är tilldelning, inte jämförelse. Det ska vara == för att jämföra värden.
Rättad rad: if gissning == kod:
(Bonus-fundering: input() returnerar alltid en sträng, så egentligen borde man skriva int(input(...)) för att kunna jämföra korrekt med talet 1234.)
Fråga 5NIVÅ A

Förklara med egna ord, steg för steg, vad koden gör. Vad skrivs ut när temp = 3?

temp = 3

if temp <= 0:
    väder = "Kallt och isigt"
elif temp <= 10:
    väder = "Kyligt"
elif temp <= 20:
    väder = "Milt"
else:
    väder = "Varmt"

print(f"Vädret är: {väder}")
Visa svar
Svar Koden kollar temp mot flera trösklar i turordning. Först kollas om temp <= 0 (falskt, eftersom temp = 3). Sedan kollas elif temp <= 10, vilket är sant (3 är mindre än eller lika med 10), så väder sätts till "Kyligt". De efterföljande grenarna (elif temp <= 20 och else) körs inte eftersom en tidigare gren redan slog till.
Output: "Vädret är: Kyligt"

Del 3 — Skriv egen kod

Försök skriva koden själv på papper eller i huvudet innan du kollar exempellösningen. Det finns ofta flera sätt att lösa samma uppgift rätt på.

Uppgift 1NIVÅ E

Skapa två variabler, stad och invånare, med valfria värden. Skriv ut en mening med hjälp av en f-sträng, till exempel: "Stockholm har 975000 invånare."

Visa exempellösning

print(f"{stad} har {invånare} invånare.")
Uppgift 2NIVÅ D

Skriv ett program som frågar användaren efter ett heltal och skriver ut om talet är positivt, negativt eller noll. Använd if-elif-else.

Visa exempellösning 
tal = int(input("Skriv ett heltal: "))

if tal > 0:
    print("Talet är positivt")
elif tal < 0:
    print("Talet är negativt")
else:
    print("Talet är noll")
Uppgift 3NIVÅ C

Skriv ett program som frågar efter vädret ("sol" eller "regn") och temperaturen, och ger klädråd enligt följande: om det regnar → "Ta med paraply.", om solen skiner och temperaturen är över 20 grader → "T-shirt räcker.", annars → "Ta med en jacka."

Visa exempellösning 
väder = input("Hur är vädret (sol/regn)? ")
temp = int(input("Vad är temperaturen? "))

if väder == "regn":
    print("Ta med paraply.")
elif väder == "sol" and temp > 20:
    print("T-shirt räcker.")
else:
    print("Ta med en jacka.")
Uppgift 4NIVÅ B

Skriv ett program som frågar efter två tal och ett räknesätt som text ("+", "-", "*" eller "/"), och skriver ut resultatet av beräkningen. Använd if-elif-else.

Visa exempellösning 
tal1 = float(input("Första talet: "))
tal2 = float(input("Andra talet: "))
op = input("Räknesätt (+, -, *, /): ")

if op == "+":
    print(tal1 + tal2)
elif op == "-":
    print(tal1 - tal2)
elif op == "*":
    print(tal1 * tal2)
elif op == "/":
    print(tal1 / tal2)
else:
    print("Okänt räknesätt")
Uppgift 5NIVÅ A

Skriv ett program som frågar efter ett användarnamn och ett lösenord, och jämför mot ett korrekt användarnamn och lösenord du bestämmer själv i koden. Använd den logiska operatorn and så att båda måste stämma för att skriva ut "Inloggad!". Annars ska programmet skriva ut "Fel användarnamn eller lösenord."

Visa exempellösning 
rätt_användarnamn = "admin"
rätt_lösenord = "python123"

användarnamn = input("Användarnamn: ")
lösenord = input("Lösenord: ")

if användarnamn == rätt_användarnamn and lösenord == rätt_lösenord:
    print("Inloggad!")
else:
    print("Fel användarnamn eller lösenord.")
